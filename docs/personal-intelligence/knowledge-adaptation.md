# Knowledge Adaptation

Knowledge-category notes can inform an answer when their normalized lexical tokens overlap the current request. The retrieved note remains labeled as user-provided reference data; the system does not claim that it independently measured the user's skill or demonstrated familiarity.

Subject-specific skill profiles, demonstrated-knowledge evidence, topic-frequency learning, and adaptation experiments are not implemented. Future work should define evidence and confidence rules, show explanations to users, and evaluate whether adaptation improves outcomes without over-assuming expertise.
