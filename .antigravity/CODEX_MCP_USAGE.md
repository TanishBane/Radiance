# Codex MCP and tool usage

## Used

- Filesystem/terminal tools: inspected Git state, dependencies, source tree, existing project notes, and ran local pnpm commands.
- CUA browser tool: opened the local Radiance app, inspected its accessibility tree and screenshot, and opened the model selector.
- Local Next development server: `http://localhost:3000` for visual inspection.
- Existing Vitest and Playwright installations for repository verification; Playwright CLI captured desktop/mobile screenshots.

## Not used

- No external accounts, GitHub, design file, deployment, or third-party MCP service was needed.
- No provider-backed chat prompt was sent, to avoid triggering external inference usage.

Screenshots are saved at `.antigravity/screenshots/radiance-desktop.png` and `.antigravity/screenshots/radiance-mobile.png`.
