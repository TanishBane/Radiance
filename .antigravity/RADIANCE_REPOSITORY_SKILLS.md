## 2. Skill Workflow Execution Strategy

1. **Audit & Truth Alignment (`documentation-and-adrs`):** Differentiate between verified implemented features (multi-provider streaming, markdown, KaTeX, dynamic themes) and unbuilt/planned items. Avoid phantom claims.
2. **README Architecture (`documentation-and-adrs` + `frontend-design`):** Clean header lockup, authentic GitHub badges (pointing to real workflows in `TanishBane/Tanixai`), concise value proposition, actual screenshots, accurate Mermaid architecture diagram, step-by-step verified quick-start.
3. **SEO & Metadata Engineering (`seo-metadata-structured-data`):**
   - Implement `src/app/sitemap.ts` (public routes only).
   - Implement `src/app/robots.ts` (disallow `/api/` and internal endpoints).
   - Enrich `src/app/layout.tsx` with complete OpenGraph, Twitter card, canonical URL, and Schema.org `SoftwareApplication` JSON-LD.
4. **Social Preview Asset Direction (`frontend-design` + `design-system`):** 1280x640 high-contrast social preview image adhering to Radiance dark violet aesthetic, official geometric symbol, and crisp typography.
5. **Community Governance (`documentation-and-adrs`):** Industry-standard `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `PULL_REQUEST_TEMPLATE.md`, and structured YAML issue templates.
6. **Documentation CI & Validation (`ci-cd-and-automation`):** Lightweight script `scripts/check-docs.mjs` verifying internal relative links, image files, environment variable consistency, plus `.github/workflows/docs.yml`.
