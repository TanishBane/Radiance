# Support for RADIANCE

Thank you for using **RADIANCE**! Below are the recommended channels for questions, troubleshooting, and assistance.

---

## 1. Documentation & Guides

Before opening an issue, please consult the official documentation:

- [Getting Started & Local Setup](docs/getting-started/installation.md)
- [Environment Configuration Guide](docs/getting-started/environment.md)
- [Architecture & System Design](docs/architecture/overview.md)
- [Operational Runbooks & Troubleshooting](docs/operations/TROUBLESHOOTING.md)
- [Testing & Quality Gates](docs/development/testing.md)

---

## 2. GitHub Issues

Use [GitHub Issues](https://github.com/TanishBane/Tanixai/issues) for:

- **Bug Reports:** Unexpected runtime behavior, layout shifts, or broken interactions. Use our structured [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature Requests:** Proposed enhancements, AI provider requests, or UX improvements. Use our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Documentation Improvements:** Typographical errors, missing explanations, or stale references. Use our [Documentation Template](.github/ISSUE_TEMPLATE/docs.yml).

---

## 3. GitHub Discussions

For open-ended questions, architectural discussions, or ideas:

- Join conversations in [GitHub Discussions](https://github.com/TanishBane/Tanixai/discussions) (if enabled on the repository).
- Share prompt workflows, custom themes, or showcase projects.

---

## 4. Security Vulnerabilities

Please **do not** report security vulnerabilities in public issues or discussions. Refer to [SECURITY.md](SECURITY.md) for private responsible disclosure instructions.
